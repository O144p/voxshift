Quick 2-Step Installation Guide

Installing on Windows (.exe)

  1. 1 Open VoxShift-Setup.exe. Because VoxShift is an independent open-source release, Windows SmartScreen may show a blue prompt—click More info then Run anyway.
  2. 2 Choose your installation folder and launch VoxShift from your Desktop or Start Menu shortcut.

Installing on Android (.apk)

  1. 1 Download VoxShift-v1.0.0.apk and tap the downloaded file in your browser or Files app.
  2. 2 If prompted for direct APK installation, tap Settings → Allow from this source, then tap Install.
